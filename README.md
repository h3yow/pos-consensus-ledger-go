# pos-consensus-ledger-go

纯 Go、零外部依赖的**权益证明链核心**：进程内确定性模拟网络承载多个验证者，
验证出块、投票、终局性、罚没与状态承诺在节点间一致且可验证。

## 快速开始

```bash
go run ./cmd/demo     # 本地 4 验证者演示（无端口、无真实网络、无时序依赖）
go test ./... -v      # 全量测试，打印每个输入与判定依据
```

## 本轮能力

- **验证者身份与签名核验**：Ed25519 公私钥体系，私钥只在本节点、公钥进创世集合；
  投票与出块均凭公钥独立验签，无私钥不能伪造投票或拼出陷害他人的双签证据；
  篡改/字段对不上的证据全网一致拒绝，同一投票重复广播仍按无害重复处理。
- **有界、可预测的交易池**：容量上限 + 明确淘汰口径（高费留下、同费留早到、
  淘汰只砍发送者后缀保证序号不断档）；同发送者同序号只允许一笔，内容不同直接
  拒绝为独立错误；新块后各节点保留集合与打包顺序一致。
- **罚没资金有明确去向**：罚没划入全网唯一的协议公共账户（计入状态根）而非消失，
  `Σ余额(含公共账户) + 手续费销毁 == 创世总量` 在任意高度任意节点可核；被罚者
  投票权重随剩余余额同步下降。

## 测试场景

- 身份绑定与证据防陷害：`consensus/identity_test.go`、`identity/identity_test.go`、
  `node/startup_key_test.go`
- 交易池容量淘汰 / 序号连续 / 同序号冲突 / 跨节点一致：`pool/capacity_test.go`、
  `node/pool_consistency_test.go`
- 罚没进公共账户、守恒、跨节点状态根、权重下降：`state/treasury_test.go`、
  `node/treasury_test.go`
- 分叉收敛（延迟 / 重复广播 / 分区）与终局保护：`node/fork_test.go`
- 双签投票 / 双 proposal 识别、1/3 罚没：`node/slashing_test.go`
- 并发出块仅调度者有效：`node/concurrent_test.go`
- 跨节点状态根一致：`node/root_test.go`
- 交易拒绝原因可区分、费用序确定：`state/`、`pool/`

完整共识规则、罚没 / 终局条件与本地多节点验证方法见
